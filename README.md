# PIT STOP

Адаптивный сайт шиномонтажа по согласованному макету. HTML, CSS, vanilla JavaScript, без сборки.

Запуск: статический сервер в корне проекта. Vercel: Other, корень репозитория, без build/install command.

Калькулятор: R13–R22, легковой/кроссовер, 1/2/4 колеса, шиномонтаж/балансировка/прокол/хранение, RunFlat. Тарифы демонстрационные; изменяются в calculator.js. WhatsApp разработчика задаётся в script.js. Форма готовит сообщение, не бронирует время и не отправляет его автоматически. Карта иллюстративная, адрес мастерской не указан.

Минимальные анимации появления отключаются при prefers-reduced-motion. Фото извлечены из согласованного макета, для реального сервиса рекомендуется заменить оригинальными.
